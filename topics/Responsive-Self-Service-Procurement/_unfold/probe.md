# Probe: Responsive Self Service Procurement in Oracle Fusion

- **Why:** Using it at work.
- **Starting point:** Uses it already; wants the deep version.
- **Scope:** Both, balanced: the end-to-end requisition flow (shop → requisition → approval → PO → receipt → invoice) plus the setup levers that shape each step (catalogs/content zones, smart forms, punchout, approvals via BPM/AMX rules, profile options and Procurement BU/requisitioning BU setup, buyer assignment, document styles, and what makes the "Responsive" UI different from the classic Self Service Procurement pages).
- **Duration:** 30 minutes.

*Research focus:* Practitioner-depth explanation of Oracle Fusion Cloud Responsive Self Service Procurement: how a requisition flows end to end and which functional setups (requisitioning BU, catalogs/content zones, smart forms, punchout, approval rules, buyer assignment, requisition-to-PO automation) control each step, plus how the Responsive UI differs from the classic SSP UI and current (25x/26x) changes.
