# Unfold: rules for every agent (Claude Code, Codex, GitHub Copilot)

Unfold turns a topic into a self-contained, animated, step-through lesson page, pitched at the learner's level, and files it in a folder tree where subtopics live inside their parent topic:

```
topics/ML/index.html
topics/ML/DL/index.html
topics/ML/DL/LLM/index.html
```

## Entry point

Select the **unfold** agent and type a topic, or run `/unfold "<topic>"` (Claude Code, Copilot) / `$unfold "<topic>"` (Codex). Either way, follow `.agents/skills/unfold/SKILL.md`. Don't start the pipeline unless the user asks.

## Layout

| Path | What |
|---|---|
| `.agents/skills/` | The five skills (canonical): `unfold`, `topic-research`, `learner-grill`, `lesson-builder`, `topic-tree` |
| `agents/` | Agent sources: `unfold` (main), `unfold-researcher`, `unfold-builder` |
| `.claude/`, `.codex/`, `.github/agents/` | Generated by `node scripts/sync-agents.mjs` (`.claude/skills` is a symlink to `.agents/skills`); don't edit |
| `topics/<…>/<Topic>/index.html` | The lesson page (generated; opens from disk) |
| `topics/<…>/<Topic>/_unfold/` | Its source and artifacts: `state.json`, `probe.md`, `research.md`, `sources.json`, `grill.md`, `PRD.md`, `lesson.json`, `scenes.js`, `build-log.md` |
| `topics/index.html` | Generated graph of the whole library (folders + each lesson's prereqs/next); rewritten on every build, move and rebuild |
| `topics/CHANGELOG.md` | One line per folder created or moved |

## Rules

1. **Never research from memory.** Facts come from web sources opened in this session and are cited `[S#]`. If you have no web tools, stop and say so.
2. **Move topic folders only with** `node .agents/skills/topic-tree/scripts/tree.mjs move …` (it logs the move and rebuilds every page).
3. **Never hand-edit an `index.html` or the player** (`.agents/skills/lesson-builder/assets/player/`). Edit `_unfold/lesson.json` / `_unfold/scenes.js` and run `build-page.mjs`.
4. **Subagents start with a fresh context**: don't fork the conversation into the researcher or builder. If your tool can't start subagents, run the skill inline.
5. **Ask the user one question at a time**, multiple choice where possible.
6. **No copyrighted media**: no film stills, posters, logos, photos of real people, or lyrics.
7. After editing anything in `.agents/skills/` or `agents/`, run `node scripts/sync-agents.mjs`.
8. Don't commit or push unless the user asks.
