# Style: 3d

**What it is.** The isometric scene rendered in real 3D: `box`, `plate` and `token` become lit three.js meshes with soft shadows, seen through an orthographic camera at exactly the kit's isometric angle, so the SVG labels, arrows and text drawn on top line up perfectly.

**What it isn't.** Not a free-roaming 3D scene (the camera is fixed so labels stay aligned; for orbitable 3D write a `mode: 'three'` scene), not photo-real.

**Materials.** Standard materials with a hemisphere light and a soft directional sun; edges outlined; `topColor` colours the top face; dashed boxes and plates become translucent with dashed edges; a shadow-catching floor.

**Colour.** Same tokens and meanings as `isometric`; lighting adds the shading.

**Motion.** Same as isometric: meshes drop, lift, glide and grow with the kit's tweens.

**Do.** Use it for layered or stacked structures (stacks, memory, blocks, layers) where depth helps; offer it as an `altStyles` entry beside `isometric`.
**Don't.** Expect it to change screen-space drawings (`rect`, `text`, charts): they stay SVG. A scene with no world primitives looks the same as `isometric`.

**Fallback.** Without WebGL the player renders `isometric` instead, automatically.

**Use for.** Data structures with height (stacks, heaps as towers), memory and storage, layered architectures, physical stacks of things.
