# Style: sketch (whiteboard)

**What it is.** An explainer drawn live on a whiteboard: marker outlines with a slight hand wobble, light washes of colour, a handwriting font, and strokes that draw themselves as the step plays.

**What it isn't.** Not a cartoon (no characters with faces, no likenesses), not messy: the wobble is a few pixels, and every label stays readable.

**Materials.** One dark marker (`ink`) for outlines; fills as light washes (about 40% of their colour); a displacement filter adds the hand wobble to every shape; Patrick Hand (OFL-1.1) for all text, bundled only when a lesson uses `sketch` or `chalk`. Background: a warm off-white board.

**Colour.** At most three marker colours carry meaning (fixed meanings); everything structural is in the dark marker.

**Motion.** Strokes draw on; text can write itself (`write: true`) for the one word that matters in a step. Sequence cause → effect with `kit.seq`, like a presenter drawing one thing, then the next.

**Do.** Use `person` and `icon` for actors and things; arrows for cause; one drawing per idea; build the board up across steps.
**Don't.** Draw hands, cursors or real people; write paragraphs on the board.

**Use for.** ELI5 tabs (a good default there), analogies, general "how does X work" explainers.
