# Question patterns

Use a mix. Easier patterns first for a concept; harder ones once recall is solid.

| Pattern | Level | Shape | Example (Stacks) | Example (non-tech: French Revolution) |
|---|---|---|---|---|
| **Recall** | easiest | "Which of these is…?" | Which operation removes the most recently added item? | Which body declared itself the National Assembly in June 1789? |
| **Recognise** | easy | "Which picture/description matches…?" | Which of these behaves like a stack: a print queue, browser Back, a playlist? | Which of these was a cause, not a consequence, of the Revolution? |
| **Apply** | medium | "Given X, what happens?" | Push 1, 2, 3, pop. What's on top now? | Prices of bread doubled in spring 1789. Which group was hit hardest? |
| **Predict the next step** | medium-hard | Show a state mid-process, ask for the next state | Stack is [4, 6], next op pop(). What is returned and what remains? | After the King's flight to Varennes, what happened to trust in the monarchy? |
| **Spot the bug / flaw** | hard | Show reasoning or code with one error | This pop() doesn't check for empty. What happens on an empty stack? | "The Revolution was caused only by Enlightenment ideas." What does this leave out? |
| **Compare** | hard | "When would you pick A over B?" | Stack vs queue for undo history? | How did Girondins and Jacobins differ on the war? |
| **Explain** | free text, once | "In one sentence, explain…" | Explain LIFO in one sentence. | Explain in one sentence why the Estates-General was called. |

## Writing good options

- Distractors come from the misconceptions list and from the most common wrong answer in the quiz seeds.
- All four options: same grammatical form, about the same length (within ~30%).
- No "all of the above", no jokes, no options that are obviously absurd.
- Rotate the correct position: across a grill, each of A-D should hold the answer at least once if you ask 6+ questions.

## Reading answers

- Fast and right at apply level → probably solid; confirm once with predict or compare.
- Right at recall, wrong at apply → shaky: they know the words, not the mechanism.
- Picked a distractor that matches a known misconception → record the misconception by name.
- "I'm not sure" → treat as unknown for that level; drop one level and ask again.
